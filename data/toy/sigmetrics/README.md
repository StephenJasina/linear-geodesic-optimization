A simple topology with two clusters connected with a critical link. This example was featured in the paper "Curvature-based Analysis of Network Connectivity in Private Backbone Infrastructures."

Important note: `toy.json` does not conform to the format of other JSON blobs used to describe networks. It instead is a relic of some older scripts that would generate CSV files from JSON configurations. To use this example, use either the CSV files or the GraphML file.
